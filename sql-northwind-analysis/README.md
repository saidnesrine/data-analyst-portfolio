# SQL Project — Northwind Traders Analysis

## Project Overview
This project analyzes the Northwind Traders sample database using SQL.
The goal is to extract business insights related to sales, customers,
products, and employee performance.

## Tools Used
- MySQL
- SQL (CTEs, Window Functions, Joins)

## Dataset
Northwind Traders — Microsoft sample database (Kaggle version)

## Key SQL Topics Covered
- JOINs
- Aggregations
- GROUP BY
- CTEs
- Window Functions
- Business KPIs

## Project Structure
sql/: SQL scripts  
insights/: business conclusions  
data/: schema  

## Business Value
This analysis helps understand customer behavior, product demand,
and overall business performance.
